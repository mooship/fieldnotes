## Hardware

- MacBook Air M4, 512GB / 16GB. Beautiful machine, and macOS is a joy to develop on.

## Editor

- [VS Code](https://code.visualstudio.com). Hard to beat the extension ecosystem.

## Terminal

- [Ghostty](https://ghostty.org): native and GPU-accelerated, with no Electron.
- Zsh with the [Starship](https://starship.rs) prompt.

## Languages and frameworks

- TypeScript with React or [Astro](https://astro.build) for anything on the web.
- .NET and C# at work.

## Infrastructure

- Cloudflare (Workers, D1, R2) is my default for hosting and storage: deploys are fast and the free tier is generous.
- PostgreSQL on [Neon](https://neon.tech) when a project needs a relational database.

## AI

- [Claude Code](https://claude.ai/code). The best reasoning of the assistants I've tried.

## This site

[Astro](https://astro.build) with static output, deployed to Cloudflare Workers and measured with Cloudflare Web Analytics (no cookies). Type is [VT323](https://fontsource.org/fonts/vt323) for headings and window titles and [IBM Plex Mono](https://fontsource.org/fonts/ibm-plex-mono) for reading and code.
